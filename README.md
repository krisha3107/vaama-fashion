# VAAMA FASHION — Website prototype

A local demonstration website for VAAMA FASHION, a clothing store
in Adajan, Surat, Gujarat, India.

Built as a Software Engineering college project (Waterfall model).
Student: Krisha Jaha | Guide: Santosh Shah
Institution: Asha M. Tarsadia Institute of Computer Science & Technology

---

## Project objectives
- Establish an online presence for Vaama Fashion.
- Showcase clothing collections organised into clear categories.
- Allow customers to browse, search, filter and prepare order enquiries.
- Provide store and contact information.
- Demonstrate a complete shopping flow (browse → cart → WhatsApp).

---

## Technology stack
- HTML5, CSS3, Vanilla JavaScript only.
- No frameworks, no build tools, no npm, no backend server.
- Browser localStorage for demo data persistence.
